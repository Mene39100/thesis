# Thesis Template

- Tesi sperimentale di Gabriele Menestrina, svolta sotto supervisione del professore Paolo Casri.

### Preparation

1. Clone

   ```sh
   git clone https://github.com/Mene39100-drive/thesis.git
   cd thesis
   ```

1. Install Dependencies

   ```sh
   npm ci
   ```

### Build

```sh
npm run build
```

### Scripts

> **Note**: Execute with `npm run <NAME>`

| **Name** | **Description**  |
| -------- | ---------------- |
| `build`  | Build PDF        |
| `check`  | Check for errors |
| `clean`  | Clean            |
| `fix`    | Fix errors       |
